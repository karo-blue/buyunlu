# 步云录

职涯成长模拟游戏，提供可直接打开或部署的网页版，以及微信小程序源码。保留季度事件、年度结算、晋升、资产、家庭、健康、关系网、结局和本地档案。

**仅限非商业使用，不授权商业化使用。** 自 1.0.2 版本起，采用[步云录非商业使用许可 1.0](LICENSE)。

## 直接打开或部署（推荐）

**网页游玩无需微信开发者工具或 AppID；打开网站须登录并验证邮箱，已有购卡账号可直接使用。**

- [打开在线网页版](https://karo-blue.github.io/buyunlu/)：手机或电脑浏览器点击即可游玩。
- iPhone / iPad：用 Safari 打开上面的在线网址。下载 ZIP 或在“文件”App 里预览本地 HTML 不等同于运行网页；请使用在线入口。
- [下载网页即用部署包](https://github.com/karo-blue/buyunlu/releases/latest/download/buyunlu-web.zip)：包含完整生成资源；自行部署须配置自己的账号后端和允许来源。
- 下载整个仓库时，网页资源位于 `docs/`，无需先构建。
- 部署到自己的静态网站：将部署包内全部文件上传到网站根目录，默认首页设为 `index.html`，通过网站地址访问。支持根目录或 `/buyunlu/` 等子路径。
- GitHub Pages：在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → /docs → Save**。

网页版存档及结局历史保存在当前浏览器本机；清除网站数据会删除存档，不同浏览器或设备不自动同步。打开网站时先检查登录状态，有效会话自动进入；未登录须登录并完成邮箱验证，退出或会话失效后重新登录。广告卡每张0.1元，最低1元、按整数元购买；发卡和扣卡由服务端确认。每张可为本局生涯累计增加3个晋升概率百分点（跨年、晋升保留，随存档保存，重开清零），或读取一次本机存档。最终概率最高100%，仍需满足其他晋升条件。所有完成登录及邮箱验证的账号均可购买。旧版免费本机卡不会转换成付费卡。

人生排行榜、老虎榜和金蝉榜联网读取原小程序同一份公共数据，登录进入后可查看，保留原有排名和历史记录。查看榜单不会上传本机成绩，源码和下载包不包含真实排行榜数据库。

有 Node.js 22 或更新版本时，也可在仓库根目录运行：

```sh
npm start
```

浏览器访问 `http://localhost:8080`。默认监听 `0.0.0.0:8080`，可通过 `HOST`、`PORT` 环境变量调整。不需要安装 npm 依赖。详见 [网页版说明](web/README.md)。

## 安装到 iPhone / iPad 主屏幕

1. 用 Safari 打开 https://karo-blue.github.io/buyunlu/ ，首次保持联网并等待游戏及离线资源加载完成。
2. 点 Safari 的“分享”，选择“添加到主屏幕”。如果出现“作为 Web App 打开”选项，请保持开启。
3. 点“添加”，以后从主屏幕的“步云录”图标启动。

本版提供独立窗口、专用图标和静态资源缓存；每次打开仍须联网确认登录状态，确认失败可重试，未登录不能进入游戏。存档仍保存在本机，不提供跨设备同步；主屏幕应用与浏览器的存储行为以设备系统为准。清除网站数据或系统清理缓存后，需要重新联网缓存资源。

这是可安装到主屏幕的网页应用，不是 IPA、TestFlight 或 App Store 安装包。尚未完成 iPhone 真机安装验证。

## 修改源码后构建

需要 Node.js 22 或更新版本，无需安装 npm 依赖。

```sh
npm run build:web
npm test
```

编辑 `game/`、`pages/` 或 `web/` 源码后重新构建，生成结果写入 `docs/`。请勿直接编辑生成资源。

## 微信小程序

使用微信开发者工具导入本目录。project.config.json 使用游客 AppID，个人开发者配置不在源码包中。需要联网服务时，将自己的 AppID、广告位和 API 地址填写到 services/config.js，并按平台要求配置自己的合法域名。所有配置默认为空。未配置微信广告时，依赖广告的操作保持不可用。

## 可选服务端

server/ 保留可独立部署的排行榜和微信虚拟支付代码。默认无支付密钥、无用户数据；启动服务会自行建立空数据目录。部署脚本中的地址均为不可用示例，需要维护者主动修改为自己的环境。任何密钥只应放在服务器环境变量中，详见 server/README.md。

## 目录

- game/：玩法、事件、职位与结局
- pages/、services/：微信页面与存储、排行榜、支付接口
- server/：可选后端，未包含真实数据库
- web/：独立网页运行层、构建与启动入口
- docs/：已构建的静态网页，可直接打开和部署
- tests/、tools/：测试与开发工具

转换工具需要显式提供有授权的 Lua 源文件：`node tools/convert-source-data.js <authorized-source.lua>`。日常运行直接使用已提交的 game/data-full.js，不需要外部源文件。
