# 步云录

职涯成长模拟游戏，提供可直接打开或部署的网页版，以及微信小程序源码。保留季度事件、年度结算、晋升、资产、家庭、健康、关系网、结局和本地档案。

## 直接打开或部署（推荐）

**网页版无需微信开发者工具、AppID、账号或服务器接口。**

- [打开在线网页版](https://karo-blue.github.io/buyunlu/)：手机或电脑浏览器点击即可游玩。
- [下载网页即用部署包](https://github.com/karo-blue/buyunlu/releases/latest/download/buyunlu-web.zip)：解压后用 Chrome / Edge 打开 `index.html` 即可游玩。
- 下载整个仓库时，直接打开 `docs/index.html`；`docs/` 已包含完整生成资源，无需先构建。
- 部署到自己的静态网站：将部署包内全部文件上传到网站根目录，默认首页设为 `index.html`，通过网站地址访问。支持根目录或 `/buyunlu/` 等子路径。
- GitHub Pages：在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → /docs → Save**。

网页版存档及榜单保存在当前浏览器本机；清除网站数据会删除存档，不同浏览器或设备不自动同步。网页版没有真实广告、支付或远程排行榜；免广告卡及晋升加成为免费本机功能。

有 Node.js 22 或更新版本时，也可在仓库根目录运行：

```sh
npm start
```

浏览器访问 `http://localhost:8080`。默认监听 `0.0.0.0:8080`，可通过 `HOST`、`PORT` 环境变量调整。不需要安装 npm 依赖。详见 [网页版说明](web/README.md)。

## 修改源码后构建

需要 Node.js 22 或更新版本，无需安装 npm 依赖。

```sh
npm run build:web
npm test
```

编辑 `game/`、`pages/` 或 `web/` 源码后重新构建，生成结果写入 `docs/`。请勿直接编辑生成资源。

## 微信小程序

使用微信开发者工具导入本目录。project.config.json 使用游客 AppID，个人开发者配置不在源码包中。需要联网服务时，将自己的 AppID、广告位和 API 地址填写到 services/config.js，并按平台要求配置自己的合法域名。所有配置默认为空。未配置微信广告时，依赖广告的操作保持不可用。

## 可选服务端

server/ 保留可独立部署的排行榜和微信虚拟支付代码。默认无支付密钥、无用户数据；启动服务会自行建立空数据目录。部署脚本中的地址均为不可用示例，需要维护者主动修改为自己的环境。任何密钥只应放在服务器环境变量中，详见 server/README.md。

## 目录

- game/：玩法、事件、职位与结局
- pages/、services/：微信页面与存储、排行榜、支付接口
- server/：可选后端，未包含真实数据库
- web/：独立网页运行层、构建与启动入口
- docs/：已构建的静态网页，可直接打开和部署
- tests/、tools/：测试与开发工具

转换工具需要显式提供有授权的 Lua 源文件：`node tools/convert-source-data.js <authorized-source.lua>`。日常运行直接使用已提交的 game/data-full.js，不需要外部源文件。
