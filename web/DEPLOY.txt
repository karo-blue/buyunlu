步云录 · 网页即用部署包 1.0.5（2026-10-17）

iPhone / iPad：用 Safari 打开 https://karo-blue.github.io/buyunlu/ 或自己部署的网址。
安装到主屏幕：Safari 打开网址并联网加载完成 → 分享 → 添加到主屏幕 → 添加。
如有“作为 Web App 打开”开关请保持开启。缓存完成后可离线打开。
这是主屏幕网页应用，不是 IPA 或 App Store 安装包。
请勿在“文件”App 预览本地 HTML，也不要安装 APK。

电脑直接游玩：解压全部文件，用 Chrome / Edge 打开 index.html。
网站部署：将本包全部文件上传到静态网站目录，首页设为 index.html。
无需微信开发者工具、AppID、npm 安装或编译，不要只上传 HTML 文件。
支持网站根目录和子路径；手机浏览器建议通过部署后的网址打开。

存档及榜单只保存在当前浏览器，换设备或清除网站数据不会保留进度。
当前在线版保留本机游戏存档和榜单；购买广告卡时使用独立购卡账号。
广告卡每张0.1元，最低1元，按整数元购买；测试期间仅对指定账号开放1元验证，以购买页为准。
游戏可以离线运行，购买和使用付费卡必须联网。旧版免费卡不会转换为付费卡。
本地文件、Fork 和其他域名不能直接调用本项目的生产收款接口；自行部署需配置自己的后端和允许来源。
