# 步云录网页即用版

## 直接使用

从 GitHub Releases 下载 `buyunlu-web.zip`，解压后用 Chrome / Edge 打开 `index.html`。下载整个仓库时，入口为 `docs/index.html`。全部网页资源已附带，首次打开不需要下载依赖、编译、登录或使用微信开发者工具。

iPhone / iPad 请用 Safari 打开 https://karo-blue.github.io/buyunlu/ 或自己的部署网址。请勿把下载 ZIP、在“文件”App 中预览 HTML、或安装 APK 当作 iOS 的运行方式。

网页已经移除启动阶段对 String.replaceAll 的依赖。iOS / Safari 真机仍需结合具体系统版本验证，手机浏览器建议使用部署后的网址打开。

手机页面采用紧凑布局，减少游戏卡片、商品页、购买页和账号弹窗的留白。按钮保留至少 44px 点击高度；输入框保留 16px 字号，避免 iOS 聚焦时自动放大。

## 安装到 iPhone / iPad 主屏幕

1. 用 Safari 打开 https://karo-blue.github.io/buyunlu/ ，首次保持联网并等待游戏及离线资源加载完成。
2. 点 Safari 的“分享”，选择“添加到主屏幕”。如果出现“作为 Web App 打开”选项，请保持开启。
3. 点“添加”，以后从主屏幕的“步云录”图标启动。

本版提供独立窗口、专用图标和离线缓存；缓存完成后可离线启动和游玩。存档仍保存在本机，不提供跨设备同步；主屏幕应用与浏览器的存储行为以设备系统为准。清除网站数据或系统清理缓存后，需要重新联网缓存资源。

这是可安装到主屏幕的网页应用，不是 IPA、TestFlight 或 App Store 安装包。尚未完成 iPhone 真机安装验证。

## 部署到网站

将 `docs/` 里的全部文件（或网页部署包内全部文件）放进静态网站目录，首页使用 `index.html`。不要只上传单独的 HTML，也不要把小程序的 `app.js` 当作网页入口。资源使用相对路径，根目录与子路径都能部署。

### GitHub Pages

在自己的仓库中打开 Settings → Pages，选择 Deploy from a branch，分支 main，目录 /docs，然后保存。等待 GitHub 构建成功，再使用设置页面给出的地址。Fork 后无需修改网页中的资源路径。

### Node.js

需要 Node.js 22 或更新版本；不需要 `npm install`：

```sh
npm start
```

默认 `0.0.0.0:8080`，首页 `http://localhost:8080`。可通过 `HOST` 和 `PORT` 调整监听地址、端口；公开部署时由自己的 HTTPS 反向代理提供域名访问。启动入口仅提供静态文件，不创建玩家账号或数据库。

## 功能与存档

人生排行榜、老虎榜和金蝉榜通过后端只读代理，读取原小程序同一份公共数据，保留原排名和历史记录。无需登录即可查看，查看时不会上传本机成绩；断网时明确提示无法连接。

保留季度事件、晋升、年度结算、家庭、健康、资产、结局、自动存档、三槽手动存档及本机结局历史。关闭或刷新页面后恢复进度与待处理事件。存档只保存在当前浏览器，切换设备、域名或浏览器不会自动迁移；清除网站数据会删除存档。

当前在线版可在原网页购买广告卡，购买时注册/登录购卡账号，游戏仍可直接游玩。每张0.1元，最低1元，按整数元购买；支付结果、发卡和扣卡以服务器确认为准。所有完成登录及邮箱验证的账号均可购买，支持支付宝手机及电脑网站支付。旧版免费卡不转换为付费卡，已有角色和本机存档保留。网页不播放微信激励广告，也不通过观看广告免费发放晋升奖励。

游戏可离线运行；购买和使用付费广告卡须联网。下载后本地运行、Fork 或其他域名部署时，不能直接使用本项目的生产支付接口。自行部署需按许可配置自己的后端和允许来源，更新 `web/site.json` 后重新构建。

购卡账号新注册用户名为 3～24 位英文字母、数字或下划线，密码为 8～20 位。登录时可输入用户名或已验证邮箱，配合同一密码进入同一账号；邮箱不区分大小写。已有中文用户名和长密码仍可登录。

同一浏览器记住登录30天，活跃使用时自动续期；切回页面会自动恢复账号，短暂连接失败不会清除登录凭据。服务器重启也保留有效会话。退出账号会撤销会话；不同浏览器的存储彼此独立，需分别登录。首次从旧版升级需再登录一次，建立可持久恢复的会话。

## 维护

`build.js` 从本仓库 `game/`、`pages/` 生成 `docs/`；`runtime.js` 提供渲染和本机存储，`offline.js` 保留本机玩法，`commerce*.js` 覆盖在线版的购卡、付费余额和用卡行为，`mobile.css` 负责屏幕适配。`site.json` 只包含公开支付 API 地址，不含商户标识或密钥。页面策略只允许指定 API 来源，主屏幕缓存不保存账号、订单、余额接口或支付页面。

```sh
npm run build:web
npm run test:web
npm test
```

`docs/` 是生成结果，请修改原始文件后重新构建。发布包必须附带 LICENSE；网页版同样仅限非商业使用，不授权商业化使用。

手动读档成功消耗 1 张广告卡，需登录并联网确认；取消或空存档不扣卡。扣卡结果未确认时可重试，不重复扣卡，暂不能切换账号或推进季度。读档不恢复已消耗的账号余额。购买页展示金额、数量和到账账号，购买须知需主动勾选；未到账、重复扣款等异常仍可核查。

已注册且完成邮箱验证的账号可在登录弹窗选择“验证码登录”，使用邮箱和6位验证码登录原账号，无需密码。验证码10分钟有效、单次使用，60秒后可重发；不会自动创建账号。密码登录仍可使用。

注册、绑定邮箱和验证码登录会在请求前提示邮箱格式错误；发送时若邮件服务明确返回地址无效、邮箱已满、拒收、繁忙或超时，页面显示对应原因及处理建议。发送受理后显示“已提交发送”，并提供“没收到验证码？”排查入口。邮箱号码填错但格式正确、或邮件稍后才被退回时，现有 SMTP 接口无法实时确认送达；当前未接入退信通知或收件箱回执，不能把发送受理当作已送达。

上线验收修复：损坏的手动存档不会被作为新局读取或触发扣卡；读取包含待处理审查/证据提醒的存档后，须先完成该决定再推进季度。购买和用卡绑定页面显示的账号，防止其他标签页更换登录后误用另一个账号的钱包。

晋升路线统一为同一广告卡入口，正文12px、标题16px，按钮保留44px触控高度。每张卡为本局生涯增加3个晋升概率百分点，跨年、晋升后继续有效，随本局存档保存，重新开局清零。其他晋升条件与每年申请次数仍须满足，最终概率最高100%。当前职级已满概率或本年度已申请时仍可为后续晋升累计加成；本局全部职级的基础概率都已满额、已结束或已到最高职级时不再新扣晋升卡。未确认的扣卡和本机写入失败保留重试，不重复扣卡。

旧存档中仍保存的加成次数会作为本局累计次数继续生效；历史版本已经覆盖掉的更早次数无法从当前存档重建。读取手动存档恢复该快照中的生涯进度与加成，不返还已经使用的账号余额。
